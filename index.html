Voltage Glitching on RTX 4090

We demonstrate the reality and danger of physical attacks by corrupting a MobileNetV2 inference with a 45 ns power glitch. The attack changes the classification — no software log ever records the intrusion.

# Run attack with auto-success detection python heatmap_glitch.py --gpu 0 \\ --model mobilenet_v2 \\ --image samples/falcon.jpg \\ --trigger-port /dev/ttyACM0 \\ --confidence-threshold 0.5

Auto-success detection: the script registers a successful attack if post-glitch confidence falls below --confidence-threshold (0.5 = 50%) or the predicted class changes.
